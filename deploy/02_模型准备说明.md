# 模型准备说明

`models/faster-whisper-small/` 只保留 `.gitkeep` 入库，模型文件由本机生成（约 490 MB，体积原因不入库）。

## 步骤

1. 确认 `requirements.lock.txt` 已安装（含 faster-whisper==1.2.1）：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
```

2. 下载模型（已内置 hf-mirror 镜像与 16 线程分块续传）：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts\download_model_bin.py
```

3. 校验（三处必须一致才算就位）：

| 文件 | 大小 | sha256 |
| --- | --- | --- |
| `models/faster-whisper-small/model.bin` | 483,546,902 B | `3e305921506d8872816023e4c273e75d2419fb89b24da97b4fe7bce14170d671` |

哈希等于 HF 仓库 `openai/whisper-small`（revision 536b0662742c02347bc0e980a01041f333bce120）的 LFS OID。

4. 断网可用性验证：拔网线（或开飞行模式）后运行 `.venv\Scripts\python.exe -X utf8 scripts\test_transcriber.py`，应仍然通过转写用例（模型已从本地目录加载，无临时联网）。

5. 同目录其余小文件来自模型仓库：`config.json`、`tokenizer.json`、`vocabulary.txt`、`preprocessor_config.json`（如脚本未带全以运行报错为准补齐）。

## 常见错误

- 模型目录缺失时，背端任务会以 `MODEL_NOT_FOUND`（可重试）落失败，health 不因此拦截启动。
- 优先使用本地校验，不走"能加载就行"的口头确认；哈希不符必须重传。
- 训练/变更模型属技术决策变更：按契约须 PM 登记后由 QA 重跑同一验收集，不得静默替换。
