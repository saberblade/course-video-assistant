## 3. 模块结构与协议（给 BE 的接入说明）

```text
modules/transcriber/
  __init__.py    # 对外 API：warmup / transcribe / cancel_current / shutdown / is_healthy
                 # 异常：TranscriberError(code, message)、TranscriberBusy
  _worker.py     # 常驻子进程入口；每次任务 {cmd:...} jsonlines 通信；模型仅在此进程加载
```

BE 调用方式（工作线程，不要在 FastAPI 事件循环直接调用）：

```python
from modules.transcriber import transcribe, warmup, cancel_current, shutdown, TranscriberError

try:
    segments = transcribe(video_abs_path, video_dir_abs_path)   # 阻塞直至 ready 数据就绪
except TranscriberError as e:
    # e.code ∈ 契约错误码；e.retryable 语义由 BE 按契约映射 error.retryable
```

- 环境变量（契约 .env 约定）：`WHISPER_MODEL_DIR/WHISPER_DEVICE/WHISPER_COMPUTE_TYPE/WHISPER_LANGUAGE/TASK_TIMEOUT_SECONDS` 均被尊重；worker 进程继承。
- `transcribe()` 内默认 1200s 墙钟期限（读 TASK_TIMEOUT_SECONDS）；BE 的看门狗也可调用 `cancel_current()` 强停。
- 分段 id 只需 BE 映射成 citation 的 `segment_id`，无需两套 ID。
- transcript.json 结构：`{segments, language, duration_sec, elapsed_sec, model_load_sec}`（utf-8）。
