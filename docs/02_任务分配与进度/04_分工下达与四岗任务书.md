# 组长分工决定与四岗任务书

版本：V1.1。分工决定人：产品经理兼小组组长。日期：2026年11月5日。

本轮统一开发“课程视频复习助手”。需求、原型、接口和验收材料已经备齐，技术路线已确定，四位成员按下面岗位直接开展工作。本文是可交给组员的正式任务书；当前只在项目文件夹交付给用户，尚未发送给成员，也没有代替成员确认接收。

## 全组共同规则

首版只做单个中文课程视频的上传、转写、章节提要、问答、原文引用、时间定位、失败重试和删除。输入是MP4/H.264/AAC，200 MiB及20分钟上限。生成问答采用通义千问API，系统工程师承担音视频与转写模块，后端承担业务和问答；不增加账号、OCR、跨视频、多轮、Docker和展示工作。

技术栈按[技术方案](../03_技术方案与接口/01_架构与技术栈.md)执行，字段按[API契约](../03_技术方案与接口/02_API与数据模型契约.md)执行。需要换栈、换模型或改字段，先写影响与证据，由组长决定并同步相关文档，不各自选一套。

## 前端工程师 FE

你负责全部用户页面与播放器交互，技术固定为Vue 3、TypeScript、Vite、Element Plus、Axios和HTML5 video。

**先读：** [PRD](../01_需求与产品设计/01_立项说明与需求文档.md)、[交互规范](../01_需求与产品设计/02_页面交互与需求调研.md)、[可点击原型](../01_需求与产品设计/03_可点击交互原型.html)、[接口契约](../03_技术方案与接口/02_API与数据模型契约.md)和[Mock](../03_技术方案与接口/04_接口Mock示例.json)。

**现在开始：** 建立首页和详情页、路由与接口类型；用既定Mock实现空态、等待态、失败态、生成回答、拒答和原文检索模式。Mock需要标明，不能当真实AI结果。M1前交页面骨架和字段核对结论。

**M2交：** 真实上传、视频列表、2秒状态轮询、播放器、转写和提要、提问与引用定位。点击引用设置start_sec并暂停，由用户继续播放。禁止在页面或产物中保存LLM密钥。

**M3交：** 删除、重试、输入边界、错误提示、生产build和构建说明。代码放`course-review/frontend/`，锁文件放`frontend/package-lock.json`，构建产物放`frontend/dist/`。这些是工程待创建的约定路径，不是当前已存在的软件。

**依赖与接收：** BE提供服务和字段，SYS提供运行地址。等待服务时先完成Mock页面；M2必须切真实接口。BE验字段，QA验行为，PM验与原型一致，SYS接收build。

## 后端工程师 BE

你负责业务API、数据、任务队列、检索问答与引用验证，技术固定为Python 3.11、FastAPI、Uvicorn单worker、SQLAlchemy 2、SQLite、jieba、rank-bm25和httpx。

**先读：** [PRD](../01_需求与产品设计/01_立项说明与需求文档.md)、[架构](../03_技术方案与接口/01_架构与技术栈.md)、[API与模型契约](../03_技术方案与接口/02_API与数据模型契约.md)、[配置约定](../03_技术方案与接口/03_环境配置与运行部署.md)。

**现在开始：** 按现有契约建表和路由骨架、错误结构、上传与状态接口；和SYS对齐转写调用，不重新设计另一套字段。M1前交可启动API骨架和协议核对结论。

**M2交：** 上传校验、持久队列、转写接入、约60秒原文提要、BM25索引、真实Qwen问答、引用回填、无依据拒答和API降级。上传202的响应字段是视频对象id，后续路径以该值作为video_id。任何模型输出的时间戳均不能直接当真值。

**M3交：** Range、重试删除、重启恢复、期限控制、脱敏日志与自测。代码放`course-review/backend/app/`，接口测试放`backend/tests/`。服务导出`backend/app/main.py`中的app，默认本机8000端口、单worker。

**依赖与接收：** SYS交transcribe模块、模型目录和环境，FE按你的真实服务联调。SYS不写业务数据库；你不代替SYS重新搭整套转写环境。FE验协议，QA验接口和正确性，SYS接服务启动入口。

## 测试工程师 QA

你负责真实样本和真值、用例执行、缺陷、指标与最终验收建议。工具采用pytest/httpx、浏览器和人工语义核验，不要求为本轮增加复杂自动化框架。

**先读：** [测试计划](../05_测试与验收/01_测试计划与验收门槛.md)、[样本脚本和25题](../05_测试与验收/02_样本脚本与问题集.md)、[结果记录](../05_测试与验收/03_测试结果与发布验收记录.md)、[API契约](../03_技术方案与接口/02_API与数据模型契约.md)。

**现在开始：** 按已有脚本录制或组织录制3段授权课程，检查格式，逐题标原文和真实秒数，登记文件哈希，锁定20道正题及5道无答案题。题目文字已写好，不能把尚未录制的视频时间写成已标注。M1前交真实素材和标注。

**M2交：** 在真实服务上独立走完整流程，验证输入、5状态、3类回答、来源定位，提交有版本和复现步骤的缺陷。

**M3交：** 完整正题分母、拒答、全部引用检查、10次时延、三段处理耗时与回归结果。**M4交：** 最终报告、冷启动与备份恢复复核、未解决问题及验收建议。所有目标值须与真实结果分开，降级不能算生成通过。

**输出：** 证据保存在`05_测试与验收/实际测试证据/<候选版本>/`，每题保存响应、真值、结论和必要日志。开发组提供固定候选版后再出最终报告；PM接收报告并作业务验收。当前不安排彩排计时。

## 系统工程师 SYS

你负责环境、音视频校验与语音转写模块、部署和数据恢复。技术固定为FFmpeg/ffprobe、faster-whisper small多语言模型、CPU int8、Windows本地运行、Python 3.11和Node.js 22 LTS。

**先读：** [技术方案](../03_技术方案与接口/01_架构与技术栈.md)、[转写模块契约](../03_技术方案与接口/02_API与数据模型契约.md)、[配置和运行约定](../03_技术方案与接口/03_环境配置与运行部署.md)、[部署交接](../04_交接文档/03_部署发布与回退交接.md)。

**现在开始：** 在目标电脑准备隔离环境、FFmpeg与模型缓存，用一段真实视频验证small CPU int8并记录版本、耗时和识别问题；从实际账户控制台取得Qwen地区端点，以服务端环境变量验证调用。M1前交真实试跑与依赖锁定证据，不能把方案上的版本当已验证版本。

**M2交：** `course-review/modules/transcriber/`模块，公开transcribe(video_path, output_dir)及契约规定的预热/取消能力，输出真实带秒数分段和受控错误。给BE独立调用成功，不写业务SQLite。

**M3交：** Windows本地启动脚本、前端同源托管、脱敏配置、日志、依赖/模型清单和一致备份方法。**M4交：** 在目标电脑冷启动与恢复副本复现，交付最终运行包和已知限制。代码与脚本按`course-review/`约定目录组织；本轮不做Docker和展示设备包装。

**依赖与接收：** BE给服务入口和数据结构，FE给生产build，QA核对环境与恢复，PM接运行包。密钥不进入前端、仓库或普通交接文件。额度与付费使用按既定配置和PM管理决定执行。
