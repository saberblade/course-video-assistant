## 数据模型

主库继续`DATA_DIR/app.db`。时间统一存UTC，页面按本地时间显示。以下为最小字段，具体ORM命名可按项目规范统一。

| 表 | 核心字段 | 约束 / 说明 |
| --- | --- | --- |
| users（新增） | id、username_normalized、display_name、password_hash、is_active、created_at | 用户名规范化后唯一；密码不存明文、不进入响应或日志 |
| sessions（新增） | id、user_id、token_hash、csrf_token、expires_at、created_at | Cookie携带随机会话值；数据库只存该值的哈希。csrf_token是绑定会话的防跨站令牌，不单独作为登录凭证 |
| videos（扩展） | 增加owner_id | 所有新上传归当前用户；旧数据可临时为空，普通用户不可读 |
| playback_progress（新增） | user_id、video_id、attempt、position_sec、furthest_sec、version、updated_at | 唯一(user_id,video_id,attempt)；保存位置与最远位置分开；version用于并发校验 |
| review_records（新增） | id、user_id、video_id、source_attempt、chapter_id_snapshot、start_sec、end_sec、text_snapshot、reviewed、saved、resolved、note、version、updated_at | 唯一(user_id,video_id,source_attempt,chapter_id_snapshot)；原章节ID是快照标识，重试后仍保留旧备注 |
| questions（已有，扩展元数据） | 原问题/回答/引用字段；增加retrieval_mode、retrieval_version | 历史查询按video.owner_id隔离；旧记录迁移为bm25，不伪称hybrid |
| rag_indexes（新增） | video_id、attempt、index_version、model、dimension、status、last_error、updated_at | 持久保存pending/building/ready/failed，记录后台构建与重启恢复状态 |
| rag_chunks（新增） | id、video_id、attempt、segment_ids_json、start_sec、end_sec、text、text_hash、chunking_version | 外键关联video，记录真实原文片段与版本；不能把LLM生成内容当原文 |
| chunk_embeddings（新增） | chunk_id、model、dimension、vector_blob、dtype、text_hash、status、updated_at | 唯一(chunk_id,model,dimension,text_hash)；建议float32 little-endian；只读同模型同维度的有效向量 |

review_records不把快照章节ID设为会随重试删除的强制章节外键。新建/更新当前章节记录时，服务器从真实章节回填快照；旧批次标记`is_stale=true`，不计当前概览。视频删除时清理该视频的进度、标记、问答、块与向量。

本轮仍保持现有重试规则：重试会重建转写/章节并清理旧派生问答。历史查询保证正常刷新可恢复，不承诺跨所有重处理批次的问答存档。页面重试确认文案保留这一说明。

## 身份与资源规则

1. 首页、登录/注册页和静态资源可公开；业务API、视频文件、转写/章节、历史/进度、RAG及付费助教API要求登录。
2. 未登录返回401；已登录访问他人的视频、章节或档案返回404。媒体Range、删除、重试、分页列表也必须执行相同校验。
3. user_id从会话取得。请求体出现user_id/owner_id等不允许字段时返回422，不相信客户端自报身份。
4. 先确认资源归属，再读取原文、向量、模型上下文或本机文件。不允许先全库检索、发给模型后再过滤结果。
5. session有效期24小时；退出令会话立即失效，清除Cookie。新登录生成新会话，过期不会默默退回“公共账号”。

会话Cookie设置HttpOnly、Path=/和明确SameSite。本机HTTP演示按开发配置设置Secure，HTTPS部署必须开启Secure；不把会话/JWT放localStorage。登录/注册核对Origin；已登录写操作使用会话绑定的`X-CSRF-Token`。该token由登录或GET/me返回，前端放内存。401清理页面状态并提示登录；403 CSRF错误不自动绕过。

注册用户名建议3—32位英文字母/数字/下划线，规范化去空白并统一大小写；显示名可用中文。密码8—128字符，Argon2id哈希；不要对密码做trim或写入日志。本阶段不做邮箱/短信验证和密码找回。

| --- | --- | --- |
| POST `/api/auth/register` | `{username,password,display_name}` → 201用户摘要 | 不返回密码哈希，不自动拿到任何旧视频；重名409 |

## 学习档案API（李沛丰）

### 播放位置

`GET /api/videos/{id}/progress`：返回当前视频attempt的进度。无记录时返回位置0、version=0，并标明尚未保存。

```json
{"video_id":"UUID","attempt":1,"position_sec":26.0,"furthest_sec":60.0,"version":3,"updated_at":"UTC时间"}
```

`PUT /api/videos/{id}/progress`：

```json
{"attempt":1,"position_sec":26.0,"expected_version":3}
```

服务器验证归属、attempt和0≤position_sec≤duration_sec。首次创建expected_version=0，成功后版本递增；furthest_sec取本次位置与服务器历史值的最大值。请求的旧版本或旧attempt返回409。客户端不能自动重放旧位置覆盖新浏览器，先重新读取，再让用户有意继续当前页面的位置。

FE每约15秒、暂停及正常离开时保存；第一次恢复需等视频元数据加载后seek，不自动播放。保存成功才显示“已保存”。最远播放位置不自动转换为章节已复习或知识掌握程度。

### 章节标记与备注

| 接口 | 说明 |
| --- | --- |
| GET `/api/videos/{id}/review-records` | 默认返回当前attempt的标记，供概览和章节状态恢复 |
| PATCH `/api/videos/{id}/chapters/{chapter_id}/review` | 创建或部分更新当前章节记录，带attempt、expected_version及至少一个changed字段 |
| GET `/api/me/review-records?status=open&limit=20&offset=0` | 当前用户的待复习清单；status支持open/resolved/all；返回旧批次时标is_stale |
| PATCH `/api/me/review-records/{record_id}` | 编辑本人已有记录的note、saved、resolved等允许字段；旧快照不影响新批次概览 |

章节请求示例：

```json
{"attempt":1,"expected_version":0,"saved":true,"note":"这一节的召回率还想再看"}
```

reviewed/saved/resolved必须为布尔，note上限2000字符，未知字段422。每次只更新显式提供字段。移出清单使用saved=false、resolved=false、note=""，保留独立reviewed标记，不能删整行误清复习状态。快照原文、时间、user_id由后端回填。

### 历史问答

`GET /api/videos/{id}/questions?limit=20&offset=0`：

```json
{"items":[],"total":0,"limit":20,"offset":0}
```

items复用现有QuestionResultOut字段，并可带检索元数据。按创建时间倒序、再按id稳定排序；前端按问题ID去重，不能每次恢复又重复插入。新POST问答仍使用现有路由，由许维护写入；李维护GET查询。

## RAG与问答扩展（卢乙源提供模块，许梓轩集成）

保留`POST /api/videos/{id}/questions`和现有answer_status/mode，不重建一套聊天接口。增加独立`retrieval_mode`（bm25、hybrid、bm25_fallback）和检索版本；生成模式仍是generative/extractive，两者不能混为一谈。
