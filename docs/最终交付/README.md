## 运行

先按[根目录 README](../../README.md)准备依赖、模型、FFmpeg 和本机 `.env.local`。密钥不进仓库。

```powershell
npm.cmd --prefix frontend run build
powershell -ExecutionPolicy Bypass -File deploy/start.ps1
```

默认地址 `http://127.0.0.1:8000/`。启动自动升级数据库，模型预热完成后健康状态才为 ok。停服使用 `deploy/stop.ps1`；开发双服务使用 `start.cmd` / `stop.cmd`。
