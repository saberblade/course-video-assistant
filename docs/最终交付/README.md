# 课程视频复习助手 · 最终交付

本目录是本次课设的交付入口。代码在仓库根目录，文档按岗位汇总到这里。

## 交付范围

一个可安装启动、有账号隔离、能保存学习档案、问答引用可回溯到课程原句的单实例服务。

- 后端：FastAPI + SQLite，串行转写执行器，后台 RAG 索引线程
- 前端：Vue 3 + TypeScript + Vite，同源托管（`frontend/dist`）
- 模型：faster-whisper-small（本地）+ 百炼 `text-embedding-v4`（向量）+ 百炼对话模型（生成）
- 数据库：Alembic 迁移链 `20261112_0001` → `20261112_0002`

## 启动与停止

```powershell
# 首次：装依赖、准备模型、配置密钥（.env.local 不入库）
.\.venv\Scripts\python.exe -m pip install -r requirements.lock.txt
Copy-Item .env.example .env.local      # 再按需填 LLM_API_KEY 等

# 构建前端（改动前端后执行）
cd frontend ; npm ci ; npm run build ; cd ..

# 启动（会自动执行 alembic upgrade head）
powershell -ExecutionPolicy Bypass -File deploy\start.ps1

# 停止（会先检查转写/索引是否仍在忙）
powershell -ExecutionPolicy Bypass -File deploy\stop.ps1
```

健康检查：`GET /api/health`，返回数据库、转写模型文件、队列长度、索引线程与索引计数。

## 已实现功能

| 能力 | 说明 |
| --- | --- |
| 账号与会话 | 注册/登录/刷新恢复/退出，Argon2id + 服务端会话 + CSRF |
| 资源隔离 | 视频、媒体 Range、转写、章节、问答、进度、标记全部按 owner 校验，他人资源返回 404 |
| 上传与处理 | 202 受理、边界校验、串行转写、失败受控、重试清派生数据、删除清媒体与索引 |
| 学习档案 | 播放进度（位置/最远位置/版本号）、章节已复习、待复习、备注、已解决 |
| 历史问答 | 分页恢复，按问题 ID 去重，旧记录标注 `bm25` 不伪称混合检索 |
| 检索增强 | 60 秒窗基线 BM25 与块级 BM25+向量 RRF，索引未就绪/向量故障如实降级 |
| 引用约束 | 引用 ID/原文/时间全部从数据库回填，不接受模型生成的时间戳 |
| 专业术语纠正 | 转写落库前纠正 ASR 同音错词（SQLite/索引/单机/部署等） |
| 维护工具 | 建号、改密并撤销会话、旧视频认领、完整性检查、索引重建 |
