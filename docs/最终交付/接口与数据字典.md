# 接口与数据字典

当前验证见[原型最终版验收](原型最终版验收.md)。健康检查额外返回 `executor`、`transcriber_worker`、`question_busy`、`assistant_busy`、`draining` 和不含路径的 `service_id`。顶层 ok 要求数据库、模型文件、预热进程和执行器就绪；未就绪或正在停服时返回 503，只读业务 API 仍可使用。停服期间新增写请求返回 `SERVICE_DRAINING`。

以代码为准：`backend/app/routers/*.py` 与 `backend/app/models.py`。
所有业务接口要求登录；未登录返回 401，访问他人资源返回 404（不暴露存在性）。

## 统一约定

- 前缀 `/api`，JSON；错误体固定为 `{"error":{"code","message","retryable"},"request_id"}`
- 会话 Cookie `session`（HttpOnly, SameSite=Lax, Path=/）
- 写操作（POST/PUT/PATCH/DELETE）需带 `X-CSRF-Token`，值由登录或 `GET /api/auth/me` 返回
- 时间统一 UTC，格式 `YYYY-MM-DDTHH:MM:SSZ`
- 分页参数 `limit`/`offset`，响应带 `total`

## 认证

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/auth/register` | `{username,password,display_name}` → 201 用户摘要；重名 409 `USERNAME_TAKEN` |
| POST | `/api/auth/login` | → `{user,csrf_token}` + 会话 Cookie；错误凭据统一 401 `INVALID_CREDENTIALS`，连续失败 429 `LOGIN_LIMITED` |
| GET | `/api/auth/me` | → `{user,csrf_token}`，供刷新恢复；无会话 401 |
| POST | `/api/auth/logout` | → 204，撤销当前会话并清 Cookie |

用户名 3–32 位字母/数字/下划线，密码 8–128 字符，Argon2id 哈希；注册不自动获得任何旧视频。

## 视频与处理

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/videos` | 上传 → 202 + `Location`；`FILE_TOO_LARGE`(413)、`UNSUPPORTED_MEDIA`(415)、`AUDIO_REQUIRED`/`DURATION_EXCEEDED`(422)、`QUEUE_FULL`(429)、`STORAGE_FULL`(507) |
| GET | `/api/videos` | 仅返回本人视频，`created_at` 倒序 + id 兜底 |
| GET | `/api/videos/{id}` | 详情；非本人 404 |
| GET | `/api/videos/{id}/content` | 媒体流，支持 `Range` → 206 + `Content-Range`，越界 416 `RANGE_NOT_SATISFIABLE` |
| GET | `/api/videos/{id}/transcript` | 转写分片；未就绪 409 `VIDEO_NOT_READY` |
| GET | `/api/videos/{id}/summary` | 章节提要（extractive） |
| POST | `/api/videos/{id}/retry` | 202；仅 `failed` 且可重试，清旧分段/章节/问答 |
| DELETE | `/api/videos/{id}` | 204；忙时 409 `VIDEO_BUSY`；成功清理媒体、转写、章节、问答、进度、标记、块与向量 |

状态机：`queued → transcribing → indexing → ready`，失败转 `failed` 并写 `error{code,message,retryable}`。

## 问答

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/videos/{id}/questions` | `{question}`（1–300 字）→ 结果；并发 429 `QUESTION_BUSY` |
| GET | `/api/videos/{id}/questions` | 历史分页，`created_at` 倒序 + id 兜底，前端按 id 去重 |

返回字段：`answer_status` ∈ `answered|not_found|degraded`，`mode` ∈ `generative|extractive`，
`citations[]`（`segment_id/start_sec/end_sec/text` 全部从库回填），
`retrieval_mode` ∈ `hybrid|bm25|bm25_fallback`，`retrieval_version`（如 `idx_v1`），`latency_ms`。

旧问答记录的 `retrieval_mode` 为空，读取时按 `bm25` 呈现，不伪称混合检索。

## 学习档案

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/videos/{id}/progress` | 当前批次进度；无记录返回 `position=0, version=0, saved=false` |
| PUT | `/api/videos/{id}/progress` | `{attempt,position_sec,expected_version}`；首次 `expected_version=0`；版本或批次过期 409 |
| GET | `/api/videos/{id}/review-records` | 当前批次的标记与备注 |
| PATCH | `/api/videos/{id}/chapters/{chapter_id}/review` | `{attempt,expected_version,reviewed?,saved?,resolved?,note?}`，至少一个改动字段 |
| GET | `/api/me/review-records` | `status=open|resolved|all`，跨视频清单，旧批次带 `is_stale` |
| PATCH | `/api/me/review-records/{record_id}` | 编辑本人记录，`expected_version` 并发校验 |

并发语义：进度与标记都用 `UPDATE ... WHERE version=?` 的原子更新，按受影响行数判定；
冲突返回 409 `VERSION_CONFLICT`（进度在别的窗口写过）或 `STALE_ATTEMPT`（视频已重新处理）。
`furthest_sec` 由服务器取历史最大值，客户端不能把它写小。
移出待复习清单用 `saved=false, resolved=false, note=""`，保留独立的 `reviewed` 标记。

## 健康检查

`GET /api/health` → `status/version/database/transcriber/transcriber_model/llm_configured/queue_pending/rag_status/rag_indexes_ready/rag_indexes_failed`。
`status=not_ready` 时返回 503；`transcriber_model` 检查 `model.bin/config.json/tokenizer.json` 是否真实存在。

## 数据表

| 表 | 关键字段 | 约束 |
| --- | --- | --- |
| `users` | id, username_normalized, display_name, password_hash, is_active, created_at | `username_normalized` 唯一 |
| `sessions` | id, user_id, token_hash, csrf_token, expires_at, created_at | `token_hash` 唯一；只存会话哈希 |
| `videos` | id, owner_id, title, status, duration_sec, attempt, error_*, local_path | `owner_id` 可空（旧数据），空值对普通用户不可见 |
| `segments` | id, video_id, start_sec, end_sec, text | 级联删除 |
| `chapters` | id, video_id, start_sec, end_sec, title, text, segment_ids_json | 级联删除 |
| `questions` | id, video_id, question, answer_status, mode, answer, citations_json, created_at, latency_ms, retrieval_mode, retrieval_version | `created_at` 索引 |
| `playback_progress` | user_id, video_id, attempt, position_sec, furthest_sec, version, updated_at | 唯一 (user_id, video_id, attempt) |
| `review_records` | user_id, video_id, source_attempt, chapter_id_snapshot, start_sec, end_sec, text_snapshot, reviewed, saved, resolved, note, version, updated_at | 唯一 (user_id, video_id, source_attempt, chapter_id_snapshot) |
| `rag_indexes` | video_id, attempt, index_version, model, dimension, status, last_error, chunk_count | 唯一 (video_id, attempt) |
| `rag_chunks` | id, video_id, attempt, ordinal, segment_ids_json, start_sec, end_sec, text, text_hash, chunking_version | 级联删除 |
| `chunk_embeddings` | chunk_id, model, dimension, vector_blob, dtype, text_hash, status | 唯一 (chunk_id, model, dimension, text_hash) |

`review_records.chapter_id_snapshot` 刻意不做外键：重试会删章节，但旧备注要保留，按 `is_stale` 标注。
