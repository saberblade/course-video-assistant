## 页面行为

- 首页为介绍页；未登录进入云台或视频时跳到登录页，成功后回到原目标。
- “我的课程”的上传、分页列表、处理状态和复习入口保留，数据按真实账号隔离。
- 导航和复习进度共用当前选中课程，课程库显示全部课程，待复习清单按跨课程范围组织。打开另一门可复习的课更新选择，切账号清空。
- 账号口令、Cookie 原文与 CSRF 不写浏览器存储。Cookie 由后端管理；写请求自动携带内存 CSRF，失败不绕过校验。
- 旧匿名记录留在原浏览器，不自动绑定或上传。旧视频不会自动归第一个账号，新账号只看到自己有权限的课程。

## 获取与运行

使用本分支同时包含的前后端源码和锁文件。Node >=22.12，后端按仓库部署说明准备虚拟环境、模型与本机配置。不要只复制前端后继续连接未支持账号的旧后端。

```powershell
npm.cmd --prefix frontend ci
# 只在缺少本机配置时复制，保留已有配置。
if (-not (Test-Path frontend/.env.local)) {
    Copy-Item frontend/.env.example frontend/.env.local
}
npm.cmd --prefix frontend run build
```

`frontend/.env.example` 为真实 API 与后端助教配置。开发页面默认 5173，`/api` 代理默认 8000；生产可用后端同源托管 `frontend/dist`。`/login`、`/screen`、`/videos/:id` 直接刷新由本分支 SPA 回退处理。构建后若后端尚未挂载前端，需要重启后端。

浏览器回归入口为 `frontend/tests/account-auth.e2e.cjs`，辅助服务为 `backend/tests/account_ui_fixture.py`。需准备 `.venv`、Chrome、可用 Playwright 模块与 `data/tmp/sample_lecture.mp4` 合成媒体。测试自行创建 `logs/account-ui-*` 临时数据、随机端口和随机口令，结束后关闭自己的服务；不操作原课程库。
