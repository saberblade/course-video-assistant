# 演示步骤（答辩动线）

目标：8–10 分钟内走完「账号 → 课程 → 复习档案 → 提问与引用 → 隔离 → 降级」这条主线。

## 0. 准备

```powershell
powershell -ExecutionPolicy Bypass -File deploy\start.ps1
# 浏览器打开 http://127.0.0.1:8000/
```

演示账号（本机已建）：

| 账号 | 密码 | 已认领视频 |
| --- | --- | --- |
| `e2e_demo` | `demo-Passw0rd` | sample_lecture、HTTP接口设计、数据库设计与备份、检索增强问答 |
| `e2e_demo_b` | `demo-Passw0rd` | 鼎利软件基本操作 |

账号不对时用维护工具重建：

```powershell
.\.venv\Scripts\python.exe scripts\maintain_accounts.py create-user --username demo_a --display-name 演示甲
.\.venv\Scripts\python.exe scripts\maintain_accounts.py reset-password --username demo_a
```

## 1. 账号闭环（约 1 分钟）

1. 打开首页 → 自动跳登录页（未登录不能看任何课程）。
2. 用 `e2e_demo` 登录 → 进入「我的课程」，列表只有本账号的视频。
3. 刷新页面（F5）→ 仍是登录态，不要求重新登录（`GET /api/auth/me` 恢复）。

讲解点：密码只存 Argon2id 哈希；会话值只在 HttpOnly Cookie 里，`localStorage` 里没有凭证。

## 2. 播放与续播（约 2 分钟）

1. 打开「HTTP接口设计」→ 播放到 30 秒左右 → 暂停。
2. 看播放器下方状态：出现「进度已保存」。
3. 关掉标签页，重新打开同一视频 → 自动回到上次位置并暂停（不自动播放）。
4. 打开另一个浏览器（或隐身窗口）登录同一账号 → 同样恢复到该位置。

讲解点：进度带 `version`，两个窗口同时改会有一个收到 409「已在另一个窗口更新」，不会静默覆盖；
`furthest_sec` 由服务器取最大值，回看不倒退。

## 3. 章节标记与待复习（约 2 分钟）

1. 右侧「章节提要」→ 选一节 → 「标记已复习」。
2. 「加入待复习」→ 写一句备注（例如「召回率和精确率的区别还要再看」）→ 保存。
3. 顶部导航「待复习清单」→ 能看到这条记录，可「标记已解决」「编辑备注」「移出清单」。
4. 刷新页面 → 记录仍在（服务端持久化，不再是浏览器本地存储）。

讲解点：移出清单只清 `saved/resolved/note`，独立的「已复习」标记保留；重试视频后旧备注按 `is_stale` 标注，不丢。

## 4. 提问与引用（约 2 分钟）

1. 回到视频详情 → 「向课程提问」。
2. 问：「HTTP请求通常包含哪些部分？」→ 回答带 2–5 条「原文依据」。
3. 点一条引用 → 播放器跳到对应时间并暂停。
4. 再问：「这段课程建议早餐吃什么？」→ 明确回答「未找到足够依据」，且没有引用。
5. 刷新页面 → 历史问答仍在（按问题 ID 去重，不重复插入）。

讲解点：引用 ID、原文、时间全部从数据库回填，模型给的时间戳不作数；无依据时拒答而不是编。

## 5. 账号隔离（约 1 分钟）

1. 退出 → 用 `e2e_demo_b` 登录 → 课程列表只剩「鼎利软件基本操作」。
2. 手动把 `e2e_demo` 的视频 ID 拼到地址栏 `/videos/<id>` → 返回 404（不是 403，不暴露存在性）。
3. 切回 `e2e_demo` → 原来的档案与问答都在。

讲解点：`user_id` 只从会话取，前端传 `owner_id` 会被 422 拒绝；他人资源一律 404。

## 6. 降级说明（约 1 分钟）

1. 打开「检索增强问答」视频，问一个需要跨段推理的问题。
2. 说明当前 `retrieval_mode` 为 `hybrid`（BM25 + 向量 RRF，索引 `idx_v1`）。
3. 若把 `.env.local` 的 `RAG_RETRIEVAL_MODE` 改成 `bm25` 重启，同一个问题仍能答，但模式会记为 `bm25`；
   索引没建好或向量接口故障时会记 `bm25_fallback`。

讲解点：降级是显式标注的，不会把回退结果说成混合检索；上游模型异常时返回 `degraded/extractive`，
只给课程原文，不伪称生成成功。

## 7. 收尾（30 秒）

`GET /api/health` 展示真实状态：数据库、模型文件、队列长度、索引线程与索引计数。
说明已知限制（单实例、无邮箱找回、样本为合成语音等），交 `已知限制.md`。
