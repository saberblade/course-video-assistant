# 原型使用边界

当前修复与实际验证以[原型最终版验收](原型最终版验收.md)为准。本页记录产品范围和证据边界，不将已修复问题继续列为待开发。

- **样本是合成语音**：真实录课质量尚未验证。旧 25 题脚本主要校验回答状态与引用，不能据此声称真实课程准确率 100%。术语纠正词表也不能覆盖所有专业词和同音错误。
- **单个服务实例与 SQLite**：同一账号在不同浏览器访问同一服务才能共享档案。默认只监听本机，未验证两台设备的局域网展示，不提供自动云同步。
- **课程范围**：中文讲课音轨，H.264/AAC MP4，≤200 MiB / 20 分钟。未实现 OCR、无音轨视频理解、跨课程自由问答或自动掌握度判断。
- **章节与导航**：章节为按时间窗提取的基础提要；连线表示时间先后，不代表知识先修关系。
- **账号维护**：没有短信/邮箱自助找回；使用交互式维护工具重置演示账号。旧匿名浏览器记录保留，不自动导入账号。
- **播放位置**：约每 15 秒、暂停或离开页面时保存；强制关闭浏览器不保证逐帧恢复。
- **模型与调用**：转写串行执行；真实生成和 embedding 需要后端 API 配置及网络，失败会显示降级。未配置模型 API 时不提供假生成回答。
- **前端体积**：Element Plus 独立包约 799 kB（gzip 约 253 kB）；已路由懒加载和分包，但尚未改为全部组件按需导入。
- **资源交接**：模型、FFmpeg、虚拟环境、数据库、课程视频与密钥不随 Git 提交；换机按清单准备。完整独立目录恢复已实测，全新物理机器安装未实测。
- **备份格式**：新版只恢复通过 `manifest.json` 校验的快照；旧的仅有 MANIFEST.txt 的备份不会自动覆盖现库，需先单独核对并转换。恢复保留旧数据和旧构建副本，需确认后人工管理磁盘空间。
