版本 V1.1　定稿日期 2026年11月5日　主责 SYS　接收人 BE、FE、QA　确认人 PM

本文是按[定稿技术栈](05_技术栈定稿与选型决策.md)执行的环境任务书和交接要求，框架、模型、运行方式均已确定。当前交付的是项目文档，course-review应用、启动脚本及依赖锁文件尚未生成。下面命令需在工程师实际创建对应文件后执行，不应在本文目录直接执行并期待应用启动。

## M1前的环境检查

SYS在M1前落实一台开发交付电脑，记录Windows版本、CPU型号、内存、可用磁盘空间、网络和浏览器版本。内存16 GB、空闲空间10 GB作为准备目标，能否满足以真实3至5分钟样本实测为准，不承诺特定硬件性能。本轮不要求展示设备、彩排或备用录像作为交付前置。

基础环境固定Python 3.11和Node.js 22 LTS（≥22.12），前端固定Vue 3、TypeScript 5、Vite 7、Element Plus 2、Axios 1，后端固定FastAPI 0.x（≥0.128）、Pydantic 2、SQLAlchemy 2。安装FFmpeg与ffprobe，并确认shell能找到其可执行文件。faster-whisper固定small多语言模型、CPU int8，不把CUDA安装当成五天前置任务。下载模型到本地models目录，用断网后加载测试确认无需临时联网。

M1完成三项真实验证：1段中文样本转写、1次Qwen真实调用、FE对Mock字段检查。任何一项未完成必须由PM记录风险；不能等到M2联调时才发现密钥、模型或媒体编码不可用。

## 配置约定

实际配置只在服务端读取，开发期使用不入库的.env.local；由BE实现配置加载，系统环境变量优先于本地配置文件。仓库只提交不含密钥的.env.example。FE只能读前端公开配置，不能添加VITE_LLM_API_KEY之类字段。

```dotenv
APP_ENV=demo
APP_HOST=127.0.0.1
APP_PORT=8000
DATA_DIR=./data
DATABASE_URL=sqlite:///./data/app.db
FFMPEG_BIN=ffmpeg
FFPROBE_BIN=ffprobe
WHISPER_MODEL_DIR=./models/faster-whisper-small
WHISPER_DEVICE=cpu
WHISPER_COMPUTE_TYPE=int8
WHISPER_LANGUAGE=zh
MAX_UPLOAD_BYTES=209715200
MAX_VIDEO_SECONDS=1200
MAX_UNFINISHED_JOBS=3
TRANSCRIBE_CONCURRENCY=1
TASK_TIMEOUT_SECONDS=1200
QUESTION_CONCURRENCY=1
RETRIEVAL_TOP_K=5
MAX_CONTEXT_CHARACTERS=6000
LLM_BASE_URL=
LLM_API_KEY=
LLM_MODEL=qwen-plus
LLM_CONNECT_TIMEOUT_SECONDS=5
LLM_TOTAL_DEADLINE_SECONDS=25
ANSWER_MODE=generative
```

LLM_BASE_URL由SYS从实际账户、地区及工作空间控制台复制，配置为OpenAI兼容接口的基础地址，BE再追加/chat/completions。不能把旧教程的通用域名当成所有账户的可用地址，不能把带/chat/completions的完整路径再次重复拼接。LLM_API_KEY必须与所用地区和工作空间匹配。LLM_MODEL固定qwen-plus。若账户权限或实际服务不可用，SYS提交阻塞证据，由BE提出可用替代及影响，经PM记录变更后才能改模型，QA重跑同一验收集；不得把模型名改成当前恰好能调用的型号后不留记录。

ANSWER_MODE=extractive是主动关闭外部生成的原文检索模式。生成模式出现API故障也可返回degraded，但必须保留内部故障码。缺失密钥时可以启动本地组件，health中llm_configured=false，页面显示原文检索模式；完整生成式问答验收不能因此判通过。

预算暂以项目人民币30元为内部管理上限，最终由PM在首次调用前确认。该数字不是厂商报价，不假设免费额度。SYS检查账户可用的额度提醒或上限设置；若平台不能硬性限额，在每轮测试前核对用量。BE记录调用次数、输入/输出token数量（服务返回时）和时间，脱敏日志不保存密钥。真实费用以控制台账单为准。

## 实现后的首次准备命令

以下均以工程师交付的course-review为工作目录，PowerShell逐条执行。具体安装位置由SYS记录，不要求修改用户全局执行策略。

```powershell

```

前提是requirements.lock.txt、frontend/package-lock.json已由SYS组织FE/BE实机验证并交付。框架与主版本选型已完成，SYS在隔离环境解析兼容补丁和传递依赖，验证后生成精确锁文件；发布包不能只写浮动包名。安装时发现不兼容应修正锁文件并重新测试，不能在QA电脑临时逐包升级。此执行责任无需再退回PM自行研究选型。

## 实现后的启动与停止

实现约定：backend/app/main.py导出app；启动时初始化数据库、检查目录、恢复中断任务、预热SYS转写模块，并托管frontend/dist。

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --workers 1
```

演示环境不使用--reload，不启动多个worker，不临时修改端口。启动后浏览器访问http://127.0.0.1:8000，另查GET /api/health。启动与health均正常后仍需真实问答验证外部连通。

正常停止先等队列清空，确认没有正在问答或删除，再在原运行终端Ctrl+C。异常中断后按设计将处理中记录改failed，不能手工修改为ready。进程残留由SYS按PID核对后停止，禁止无差别结束所有Python进程。

开发期FE可单独使用Vite，代理/api到8000；交付前必须验证构建后的同源版本，不能只测试开发服务器。静态页面刷新、资源路径和/api路由优先级均需要测试。

## 模型模块验收

SYS交接modules/transcriber源代码、版本锁定、模型下载来源与许可、模型目录结构、样本耗时、正确输出JSON和失败样本。用固定输入验证warmup、transcribe、cancel_current、shutdown，接口细节见[API契约](02_API与数据模型契约.md)。

必须证明：中文文本非空、时间单位为秒、时间不超视频长度、取消后不存在残留FFmpeg或模型子进程、断网仍可本地转写。small、CPU int8为已定技术决策。若真实样本在目标机器不满足时间目标，SYS先提交耗时和错误证据、排查环境，再提出缩短测试输入或模型替代的影响；变更须由PM登记，QA重跑相同验收题，不能悄悄换模型后沿用旧测试结果。

首次下载和第一次模型加载耗时分别记录，正式性能数据在预热后采集；视频处理耗时从transcribing开始到ready或failed结束，排队耗时另记。3至5分钟样本不超过8分钟是验收目标，未测前不写“8分钟内完成”。

## 日志与故障定位

每条关键日志至少包含UTC时间、级别、request_id、video_id（如有）、阶段、错误码和耗时。转写开始/结束、队列长度、重试、API调用状态、引用验证失败、删除和启动恢复必须可查。日志不记录Authorization、不打印.env、不保存完整视频原文和用户个人信息。

| 现象 | 首先检查 | 主责与交接 |
| --- | --- | --- |
| 无法启动 | Python/锁文件、端口占用、目录写权限 | SYS定位环境，BE处理服务异常 |
| 视频无法播放或跳转 | 编码、Content-Type、Range 206/416 | SYS确认样本，BE修文件响应，FE验播放器 |
| 一直排队 | worker是否启动，是否存在未释放锁 | BE查看状态与日志，SYS确认进程 |
| 转写失败或很慢 | 模型目录、CPU内存、音轨、任务期限 | SYS给出诊断与样本证据 |
| 问答返回degraded | 配置、地区密钥、网络、额度、25秒期限 | SYS验证账户，BE记录上游错误 |
| 原文有答案但拒答 | 分词、术语、候选片段、模型JSON与引用检查 | BE与QA按固定题复现 |
| 删除失败 | 视频级锁、文件占用、回收区与SQLite一致性 | BE核对事务，SYS检查本地文件 |

## 当前验收中的异常路径

- 使用真实授权样本验证上传、状态、问答、拒答、引用定位，不以Mock代替真实处理。
- 断网时检查本地播放、章节、原文定位和extractive检索模式，明确外部生成能力不可用。
- 本地服务无法启动时按日志定位，不以历史录屏代替产品验收。
- 按用户最新要求，展示、彩排、投影、备用录像等工作暂缓；已有展示文件不作为本轮技术交付或验收前置。
