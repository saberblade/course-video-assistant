- 会话由 HttpOnly Cookie 管理，Axios 携带 Cookie，CSRF 只存内存并自动用于写操作。401 清理私有页面并跳登录；403 提示错误，不盲目重试。

- 登录后按配置调用站内助教后端，读取真实 `generative/guide`；匿名首页只用明确标识的内置指引。登录页隐藏悬浮按钮，避免遮挡表单。
- 补充后端 SPA 回退对 `/login` 的支持与刷新回归，未改写同学的认证、资源权限或数据库方案。
- 课程知识导航与复习进度共用当前课程；经过课程库、清单或首页再返回仍保留选择，刷新和历史返回按 URL 恢复。课程库保持全部课程，清单保持跨课程范围；打开另一门可复习课程更新上下文，换账号清空。
- 按用户要求移除“真实接口”“账号独立”、旧匿名记录迁移等界面提示，开发与迁移信息留在文档。操作错误、会话过期和不可用状态保留简短反馈。

## 实际已接接口

| 接口 | 请求 / 响应 | 前端处理 |
| --- | --- | --- |
| POST `/api/auth/register` | `{username,password,display_name}` → 201 `{id,username,display_name}` | 账号规范化提示；409 重名；成功回登录，清空密码 |
| POST `/api/auth/login` | `{username,password}` → `{user,csrf_token}` + Cookie | 内存保存用户与 CSRF，回原页面；错误凭据 401 不触发已登录过期流程 |
| GET `/api/auth/me` | `{user,csrf_token}`，匿名 401 | 刷新恢复，8 秒连接超时；公共首页不因服务不可达一直空白 |
| POST `/api/auth/logout` | `X-CSRF-Token` + Cookie → 204 | 服务端成功撤销会话后清理本机页面；失败显示错误 |
| 现有视频 API | 路径和数据不变，新增会话 / 写操作 CSRF | 列表、上传、详情、转写、章节、问答、重试、删除复用统一请求层 |
| POST `/api/assistant/chat` | `{messages:[{role,content}]}` → `{answer,mode}` | 登录后调用，区分模型回答 / 基础指引；失败不伪装成功 |

身份不由 user_id/owner_id 请求字段决定。密码、会话值和 CSRF 均不写 localStorage/sessionStorage。

## 待服务端交付的边界

此次远端只有账号 / 资源隔离分支，尚无 DB-02、DB-03、DB-04 学习档案实现。这些属于批准范围，未标记完成。

| 待联调接口 | 前端仍需完成的联调 |
| --- | --- |
| GET / PUT `/api/videos/{id}/progress` | 约 15 秒、暂停及离开保存；metadata 后恢复且不自动播放；version/attempt 冲突提示 |
| GET `/api/videos/{id}/review-records`；PATCH `/api/videos/{id}/chapters/{chapter_id}/review` | 数据库标记与备注、部分更新、保存反馈、409 冲突 |
| GET `/api/me/review-records`；PATCH `/api/me/review-records/{record_id}` | 跨视频清单、已解决 / 移出独立状态及旧快照 |
| GET `/api/videos/{id}/questions` | 问答历史分页、按 ID 去重与刷新恢复 |
| GET `/api/videos/{id}/retrieval-status` | 真实检索状态与降级展示，待 RAG 模块合入 |

真实模式当前显示“复习记录暂不可用”或“待复习清单暂不可用”，章节标记按钮置灰，暂不能新建复习标记 / 备注，不显示伪造的 0% 或保存成功。旧匿名 localStorage 原样保留，不自动认领、导入或用于当前账号统计，页面不再展示迁移说明。课程导航、浏览、播放、单次课程问答照常使用；问答历史仍仅在本页显示。
