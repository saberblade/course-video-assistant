# 工程验收演练与模拟数据

V1.2 · 2026年11月5日 · 产品经理兼组长

**数据属性为模拟。** 本页的候选版本、样本时间、问答输出、耗时和缺陷是课程原型的演练输入。使用 A01 至 N05 演示如何计算指标、判断缺陷等级并做出发布决策。实际浏览器走查单列在[原型验收报告](04_原型产品验收报告.md)，工程证据留在[测试结果记录](03_测试结果与发布验收记录.md)。

## 演练条件与结论

设定 11 月 11 日 M3 上午预审候选版本 `SIM-RC-01`。模拟使用 3 段 3 至 5 分钟的中文录课，按[固定题集](02_样本脚本与问题集.md)给出 20 道正题和 5 道无答案题。转写按预热后记录。片段秒数按视频起点计算，表中用「目标秒 → 点击后秒」表示定位对照。

**模拟发布裁决为退回整改。** 正题和拒答达到数量门槛。B03 的答案把 SQLite 事务错误地说成能回滚视频文件写入，引用内容与结论相反，记为 S2。另有一次问答超过 20 秒的目标。先修复 B03 并复测同类题，再按同一分母跑完整题集，复核时延和备份恢复证据。
