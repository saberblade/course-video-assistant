# 组员先读 开工与阅读顺序

项目：课程视频复习助手。版本：V1.3。日期：2026年11月7日。产品经理兼组长负责需求、原型、分工、技术决策与协调。

## 如何打开

先把整个压缩包解压到同一个文件夹，再双击[开始阅读.html](开始阅读.html)。可以搜索和按分类阅读，也可以打开[Word手册](项目执行与交接手册.docx)。不要只从压缩包内单独打开某个HTML文件，否则配套资料可能打不开。

## 每个人先读什么

1. 全组先读[PRD](01_需求与产品设计/01_立项说明与需求文档.md)，再点开[可点击原型](01_需求与产品设计/03_可点击交互原型.html)体验用户流程。
2. 阅读[正式分工与四岗任务书](02_任务分配与进度/04_分工下达与四岗任务书.md)和[技术栈定稿](03_技术方案与接口/05_技术栈定稿与选型决策.md)，按照下面自己的岗位开工单开展工作。
3. FE与BE对齐[API契约](03_技术方案与接口/02_API与数据模型契约.md)和[Mock样例](03_技术方案与接口/04_接口Mock示例.json)；SYS与BE同时对齐转写模块契约；QA核对需求与测试口径。

| 岗位 | 直接打开 | 第一项交付 |
| --- | --- | --- |
| 前端 FE | [前端开工单](岗位开工单/前端工程师.md) | 页面骨架、接口类型、Mock五状态与三类回答 |
| 后端 BE | [后端开工单](岗位开工单/后端工程师.md) | API骨架、数据库与上传任务，和SYS对齐转写调用 |
| 测试 QA | [测试开工单](岗位开工单/测试工程师.md) | 三段真实授权视频、25题人工答案与真实时间标注 |
| 系统 SYS | [系统开工单](岗位开工单/系统工程师.md) | 固定环境、依赖与模型缓存、真实转写和API试跑 |

## 共同节点

- 11月6日下班前：工程接收、环境与协议验证、样本标注。
- 11月10日中午前：真实视频从上传到问答、来源回看跑通。
- 11月11日下班前：候选版本冻结、核心回归、运行包。
- 11月12日下班前：正式验收与备份恢复。
- 11月13日：整改、复测与归档缓冲。开场 PPT 单列为立项说明。

## 开工时确认的内容

阅读后向组长说明“岗位、已接收的任务、第一项交付、当前阻塞或疑问”。交付时写任务ID、版本/文件、复现步骤、实际结果、已知问题和接收人。不要各自换栈、改接口或加功能；有必要变更先说明影响与替代方案。


## 本轮补齐的资料

先查外部研究与竞品，理解立项取舍。模拟调研保留原始记录，原型浏览器复测独立归档。FE 和 QA 可以沿 10 张需求工单从需求追到用例。组长按试点规则核对准备时间、可核对完成率和就绪查找时间。
