# 测试工程师 开工单

版本V1.1。组长已确定需求、分工和技术路线；按本单立即开工。完整要求以[正式任务书](../02_任务分配与进度/04_分工下达与四岗任务书.md)和[技术决策](../03_技术方案与接口/05_技术栈定稿与选型决策.md)为准。


你负责真实样本和真值、用例执行、缺陷、指标与最终验收建议。工具采用pytest/httpx、浏览器和人工语义核验，不要求为本轮增加复杂自动化框架。

**先读：** [测试计划](../05_测试与验收/01_测试计划与验收门槛.md)、[样本脚本和25题](../05_测试与验收/02_样本脚本与问题集.md)、[结果记录](../05_测试与验收/03_测试结果与发布验收记录.md)、[API契约](../03_技术方案与接口/02_API与数据模型契约.md)。

**现在开始：** 按已有脚本录制或组织录制3段授权课程，检查格式，逐题标原文和真实秒数，登记文件哈希，锁定20道正题及5道无答案题。题目文字已写好，不能把尚未录制的视频时间写成已标注。M1前交真实素材和标注。

**M2交：** 在真实服务上独立走完整流程，验证输入、5状态、3类回答、来源定位，提交有版本和复现步骤的缺陷。

**M3交：** 完整正题分母、拒答、全部引用检查、10次时延、三段处理耗时与回归结果。**M4交：** 最终报告、冷启动与备份恢复复核、未解决问题及验收建议。所有目标值须与真实结果分开，降级不能算生成通过。

**输出：** 证据保存在`05_测试与验收/实际测试证据/<候选版本>/`，每题保存响应、真值、结论和必要日志。开发组提供固定候选版后再出最终报告；PM接收报告并作业务验收。当前不安排彩排计时。


## 提交要求

写任务ID、代码/材料版本、复现步骤、实际结果、已知问题、交给谁。预计阻塞半个工作日就报告影响与所需输入。角色对应唯一成员，不以未填姓名为由等待。
