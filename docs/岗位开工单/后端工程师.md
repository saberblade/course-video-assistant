# 后端工程师 开工单

版本V1.1。组长已确定需求、分工和技术路线；按本单立即开工。完整要求以[正式任务书](../02_任务分配与进度/04_分工下达与四岗任务书.md)和[技术决策](../03_技术方案与接口/05_技术栈定稿与选型决策.md)为准。


你负责业务API、数据、任务队列、检索问答与引用验证，技术固定为Python 3.11、FastAPI、Uvicorn单worker、SQLAlchemy 2、SQLite、jieba、rank-bm25和httpx。

**先读：** [PRD](../01_需求与产品设计/01_立项说明与需求文档.md)、[架构](../03_技术方案与接口/01_架构与技术栈.md)、[API与模型契约](../03_技术方案与接口/02_API与数据模型契约.md)、[配置约定](../03_技术方案与接口/03_环境配置与运行部署.md)。

**现在开始：** 按现有契约建表和路由骨架、错误结构、上传与状态接口；和SYS对齐转写调用，不重新设计另一套字段。M1前交可启动API骨架和协议核对结论。

**M2交：** 上传校验、持久队列、转写接入、约60秒原文提要、BM25索引、真实Qwen问答、引用回填、无依据拒答和API降级。上传202的响应字段是视频对象id，后续路径以该值作为video_id。任何模型输出的时间戳均不能直接当真值。

**M3交：** Range、重试删除、重启恢复、期限控制、脱敏日志与自测。代码放`course-review/backend/app/`，接口测试放`backend/tests/`。服务导出`backend/app/main.py`中的app，默认本机8000端口、单worker。

**依赖与接收：** SYS交transcribe模块、模型目录和环境，FE按你的真实服务联调。SYS不写业务数据库；你不代替SYS重新搭整套转写环境。FE验协议，QA验接口和正确性，SYS接服务启动入口。


## 提交要求

写任务ID、代码/材料版本、复现步骤、实际结果、已知问题、交给谁。预计阻塞半个工作日就报告影响与所需输入。角色对应唯一成员，不以未填姓名为由等待。
