# 测试与验收

测试工程师维护 `cases/` 中的用例、`fixtures/` 中的脱敏小样例，以及 `evidence/` 中的实际复测记录。授权录课原文件保存在本机，仓库只记录样本标识、哈希、授权和获取方法。模拟数据、历史证据与本轮真实测试必须明确区分。

## 目录

| 目录 | 内容 | 提交规则 |
| --- | --- | --- |
| `cases/` | F01–F36 用例、预期和候选版实际状态 | 保留失败、部分和阻塞，不只提交通过项 |
| `fixtures/` | 固定 20+5 题、正式样本 manifest 模板 | 只提交脱敏数据和空模板，不提交授权原视频或本机绝对路径 |
| `evidence/<commit>/` | JUnit、浏览器检查、备份恢复、报告与质量检查单 | 对应一个明确提交；证据生成后不覆盖旧候选版本 |
